Installing Marrowdeck 4.17 (archived)

Status of this page

This page describes the 4.17 line of Marrowdeck. The 4.17 line is archived. It receives no further fixes, and the current line is 4.18. The instructions below are kept for sites that have not upgraded.

Installing on RHEL-family systems

For Rocky Linux, AlmaLinux and Red Hat Enterprise Linux 9, install the server package marrowdeck-srv. The 4.17 line needs version 4.17.3 or newer of marrowdeck-srv.

sudo dnf install marrowdeck-srv

Installing on Debian-family systems

On Debian and Ubuntu, install marrowdeck-server version 4.17.1 or newer.

Marrowdeck is a made-up product used to test an assistant's web reading. Copyright the Marrowdeck authors.
