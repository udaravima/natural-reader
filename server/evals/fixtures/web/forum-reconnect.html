Tiles stay grey after a network interruption

Question

My wall display shows the board but the tiles stay grey after a network interruption. The server is Marrowdeck on Debian 12. Is there a setting to make it reconnect?

Answer

The board reconnects on its own. Grey tiles after a long interruption mean the display's sign-in expired; reload the page and sign in again. A display that cannot sign in should use a collector key with read access instead.
