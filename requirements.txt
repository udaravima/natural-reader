# ONNX Runtime for Kokoro: the CPU build. kokoro-onnx itself requires
# `onnxruntime`, so listing an accelerated build here as well installs BOTH
# into the same onnxruntime/ folder; the later one overwrites the other and
# the app silently runs on CPU (that is what happened with
# onnxruntime-openvino). To accelerate, swap it in a venv after installing:
#   NVIDIA:            pip uninstall -y onnxruntime && pip install onnxruntime-gpu
#   Intel GPU/NPU/CPU: pip uninstall -y onnxruntime && pip install onnxruntime-openvino openvino
# then check the startup line "Available ONNX Runtime providers".
onnxruntime
